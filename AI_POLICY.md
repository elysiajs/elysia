## AI-assisted contributions

## AI-assisted are allowed

All issues and pull requests must be reviewed by a human maintainer before create or merged.

All code must be reviewed and tested by a human maintainer before merged.

Please personally review and test all AI-generated content, understand the proposed changes and be able to respond to maintainer feedback.

### Fully automated are not welcome

All pull requests and issues must be created by a human. Using AI to create one are not welcome.

This is to prevent spam and low-quality contributions. The maintainers reserve the right to close any pull request or issue that is fully automated or low-effort without further discussion and may result in a contribution ban.

Submitting multiple automated or low-effort pull requests within a short period may be treated as spam and may result in a contribution ban.
